# Quality tier from graph embeddings

Generated by `make gds`. Label: `high` if points >= 90, else `standard` (38% of 119,929 wines are `high`). Features: FastRP embedding (size 64) only; points and price are not inputs. 80/20 stratified split. The tiers are imbalanced, so macro F1 is the main metric: always guessing the majority tier already gets a high accuracy.

| Model | Accuracy | Macro F1 |
|---|---|---|
| Always predict the majority tier | 0.620 | 0.383 |
| Logistic regression on FastRP | 0.599 | 0.591 |
